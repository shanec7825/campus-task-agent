## 问题

1. **文档与代码漂移风险**：端口（8000 / 5173）、演示账号、env 变量名一旦与代码不一致，评委按 README 复现就会失败。处置：把三项做成逐项比对表，交付前用脚本核对（`readme/README.md` 第 3、4、6 节）。
2. **脚本在干净环境不可复现**：安装脚本必须在「已有 `.venv` / `node_modules`」与「全新环境」两种状态下都能跑。处置：幂等设计（已存在则保留不删除），并在 Windows 上避免依赖 WSL。
3. **留痕造假红线**：`codearts_proof` 中未实际发生的阶段只能写占位。处置：阶段文件统一标注「对话原文待该阶段收尾由哨兵整理」，`LOG.md` 顶部写明记录口径。
4. **Key 泄漏红线**：文档、脚本、前端源码均不得出现真实 Key。处置：示例值统一 `your-...-here` 风格占位，交付前做凭证前缀扫描与 `MAAS_API_KEY` 前端扫描双检。
5. **待办**：华为云部署、演示视频录制、五目录 zip 打包尚未发生，本文件保留 ⏳ 标记，不填虚假结果。
