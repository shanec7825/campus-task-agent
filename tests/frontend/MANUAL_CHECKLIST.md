## 0. 通用前置条件（每一项默认继承）

| 条件 | 要求 |
|---|---|
| 浏览器 | Chrome 或 Edge（语音依赖 `webkitSpeechRecognition`；Firefox 不支持） |
| 页面地址 | **`http://localhost:5173/`**（或备选 `http://localhost:5174/`）；**不要用 `127.0.0.1`**（Vite 5 仅监听 localhost/IPv6，实测 `127.0.0.1` 无响应） |
| 后端 | `8000` 端口运行；离线演示设置 `MAAS_MOCK=1`（AI 走 mock 规则，结果可预期） |
| 账号/会话 | 需要发布者与执行者两个**互相隔离的浏览器会话**：普通窗口登录 `teacher01`，隐身窗口登录 `student01`（共用 localStorage 会导致互相顶号） |
| 麦克风 | 首次点录音需授权；无麦克风设备可用"文本输入 + AI 解析"覆盖非语音项 |
| 网络面板 | DevTools → Network，筛选 `stream/parse`；显示方法/状态/时间/请求体 |
| 证据 | 每项至少 1 张截图；语音项必须同时截 **Network 面板** 与 **界面染色**（这是证明切片算法生效的唯一形式） |
| 数据准备 | 冷启动为空库：先由 `teacher01` 发布 1~3 条任务（如"秋之韵晚会搬桌椅"），否则相似提示条与大厅列表无数据可验 |
