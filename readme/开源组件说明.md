# 开源组件说明

本项目在前后端选型上坚持「成熟、轻量、可复现」原则，除华为云码道（CodeArts）与本项目自研代码外，使用的主要开源组件如下。

版本列同时给出两种口径：
- **声明版本**：`backend/requirements.txt` 与 `frontend/package.json` 中的版本约束（宽下限 / 兼容范围）；
- **实测版本**：本工程当前环境实际安装的版本（`pip list` / `package-lock.json`），供复现参考。

## 三、运行时外部服务（非开源组件）

| 服务 | 用途 | 说明 |
|---|---|---|
| 华为云 MaaS（ModelArts Studio） | 提供 `DeepSeek-V4.1-Flash-1017` 等模型，OpenAI 兼容协议 | 由 `backend/.env` 的 `MAAS_API_KEY` / `MAAS_BASE_URL` / `MAAS_MODEL` 配置；不配置则进入离线 mock 模式 |
| 华为云码道（CodeArts） | AI 原生开发平台，Agent Team 多智能体协作编码 | 使用痕迹见 `codearts_proof/`，不属于运行时依赖 |

## 四、说明

1. 本项目**不引入** axios、UI 图标字体、CSS 框架等额外依赖：HTTP 统一使用浏览器原生 `fetch`，样式为手写 CSS 变量（字段颜色池见 `frontend/src/styles/color-pool.css`），以降低版本冲突与离线构建风险。
2. 依赖版本采用「宽下限不锁小版本」策略（见 `requirements.txt` 注释）；唯一例外是 APScheduler 限制主版本 `< 4`，因为 4.x 的 API 与 3.x 不兼容。
3. 所有组件均通过 PyPI / npm 官方源安装，未使用私有分支或修改版。
